# Token Optimization

## Defaults

- Router plus working profile for quick tasks.
- One project context at a time.
- Authorities loaded only for matching tasks.
- Metadata and headings before full content.

## Limits

- Root `memory.md`: target below 3,000 tokens; review at 4,000; hard warning at 6,000.
- Root `handoff.md`: target below 2,000 tokens.
- Warning file size: 20 KB.
- Large file: 50 KB.
- Very large file: 200 KB.

For large files, inspect headings, search relevant terms, read only the matching section, and prefer indexes or summaries.
