# Set up KOS Community

Open Codex, Claude Code or Gemini CLI in your vault or an empty folder. Paste this prompt. You can also name a different target folder in the same message.

```text
Install or update KOS Community here from https://github.com/kravetech/kos-community. Follow “First run with an agent” in the repository’s INSTALL.md. Let me approve the proposed locations and changes, then show me what changed in my vault.
```

A new vault needs one approval. An update shows the changes since your installed version and asks once to back up and rehearse, then once to update the original. A current vault finishes immediately. First use requires a published Community installer with the guided launcher, introduced in 1.4.0. [Guided setup](../../INSTALL.md#guided-setup)
