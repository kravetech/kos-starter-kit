# Validation Checklist

- [ ] Required root files exist.
- [ ] Required numbered directories exist.
- [ ] JSON files parse.
- [ ] No unresolved `{{tokens}}` remain.
- [ ] Canonical router is compact.
- [ ] Claude and Codex adapters are thin.
- [ ] Memory and handoff limits are documented.
- [ ] Reports, state, history, attachments, and inventories are excluded from bootstrap.
- [ ] Automation registry exists.
- [ ] External automations are `Not configured`.
- [ ] Installer state and installation report exist.
- [ ] Privacy scan reports no blocking findings.
- [ ] No Git remote or push was configured.
